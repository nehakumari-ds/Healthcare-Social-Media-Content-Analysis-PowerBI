## Healthcare Social Media Content Performance — Power BI Dashboard

A Power BI dashboard that analyzes healthcare social media performance across major platforms.
It highlights engagement trends, views, follower growth, and content-type effectiveness for data-driven insights.

## Project Overview

This dashboard visualizes key metrics from healthcare-related social media content posted on platforms such as YouTube, Instagram, TikTok, Twitter/X, and Facebook. It helps understand audience behavior, evaluate platform performance, and identify high-impact content.

## Features
• Engagement rate analysis  
• Follower count trends across platforms  
• Content type performance (video, image, reel, post, etc.)  
• Views and interaction metrics  
• KPI cards for quick insights  
• Interactive slicer for post title filtering  
• Clean and modern dashboard layout  

## Tools Used
• Power BI Desktop  
• Microsoft Excel  
• DAX (Data Analysis Expressions)  
• Data Modeling  
• Data Cleaning & Transformation  
• Data Visualization
